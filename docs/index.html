Phoenix Lights (1997): Quick Signal Report

Main finding: public instrument datasets show a strong, timestamped anomaly cluster in the same event window.

Project in one paragraph

We model the event timeline, pull public sensor streams for the same time window, normalize each stream with rolling sigma, and flag overlap windows where multiple lenses spike close together. For Phoenix 1997, the strongest overlaps are in the event window.
