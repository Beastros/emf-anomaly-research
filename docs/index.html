Phoenix Lights (1997): Public Instrument Signal Report

This project tests a simple idea: when a well-documented event has a known timeline and route, do independent public sensor archives show unusual behavior in the same window?

What this project is

UAP Sniffer is a reproducible multi-lens analysis pipeline that combines: witness track timing + magnetometer streams + weather/radar/space-weather context to score event-window anomalies.

  • Event tracks are modeled from reported positions/timestamps.
  • Sensor streams are normalized with rolling-baseline sigma scoring.
  • Cross-lens overlap windows are extracted as convergence markers.

Why this is interesting

The goal is not to prove mechanism claims from one dataset. The goal is to locate and preserve timestamped, reproducible markers in public archives that align with event timing.

For Phoenix 1997, the primary marker is a strong event-window geomagnetic/radar coincidence.
