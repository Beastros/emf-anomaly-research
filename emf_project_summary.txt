WHAT WE BUILT
-------------
A multi-sensor anomaly detection framework ("UAP Sniffer") that cross-correlates
independent public government sensor datasets against documented anomalous events.
Core idea: point every available sensor at the same event and ask what each one
independently recorded. When unconnected instruments flag the same moment from
different locations, that convergence is physically meaningful.

Repo: https://github.com/Beastros/emf-anomaly-research
Live report: https://beastros.github.io/emf-anomaly-research/

THE CORE EQUATION
-----------------
ACS(t, p) = sum_n [ w_n * sigma_n(t,p) * G(Kp) * N(s,t) ]

sigma_n = rolling 20-min baseline sigma score for lens n
G(Kp)   = 1.0 if Kp < 3 (solar gate), 0.2 if Kp >= 3
N(s,t)  = null-return score for radar station s
w_n     = lens weight (magnetometer=1.0, nexrad=0.8, kp=0.6)

ALGORITHMS
----------
1. Rolling baseline: sigma_i = |x_i - mean(window)| / std(window), window=20min, flag >2.0
2. Kp solar gate: Kp < 3.0 -> solar ELIMINATED
3. Null return scorer: N(s) = 1 - (files/expected) within coverage radius
4. Cross-station wavefront: Pearson correlation with time lag; velocity = distance/best_lag
5. Convergence engine: flag if >=2 independent lenses anomalous within +-10min window
